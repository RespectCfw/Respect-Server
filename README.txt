RESPECT Website - Starter

Files:
- index.html : page content and sections
- style.css  : visual design and responsive layout
- script.js  : mobile navigation and rules tabs

Before publishing:
1. Replace the Discord links (currently generic discord.com links) with your actual invite.
2. Review and replace sample rules with the official RESPECT rules.
3. Add approved founder names/photos and actual application destinations.
4. The activation form is currently an information/steps section only. A real form that receives applications needs a secure backend; do not put bot tokens or private credentials in these front-end files.
5. The logo currently references the saved RESPECT Roblox asset ID. Replace it if you want a different logo file.

Publish using GitHub Pages: upload these files to a repository, enable Pages from the repository Settings, and select the main branch/root folder.
